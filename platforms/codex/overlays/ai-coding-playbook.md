description: >
  当用户需要 AI coding 工作流支持时必须使用。短语如“梳理需求、确认需求、做方案、写方案、做 UI Flow、做原型、拆任务、执行任务、开始实现、继续 Goal、续跑、app goal 进度条、做 CR、review、测试范围、Git 分支、同步主干、merge main、rebase main、发布检查、上线、发版、发测试、发生产、已 merge 后部署下、排查问题”都应触发。覆盖需求、方案、设计、领域/数据/API/DTO/ViewModel/状态、任务拆解、实现、验证、CR、测试、Git 安全、发布安全、排障，以及 NestJS/React/TypeScript/PostgreSQL/TypeORM、Chrome 插件、AI provider 链路。用户即使没有说“参考 playbook”，只要是在做研发方案、实现、测试、评审、Git 分支处理、明确发布或排障，都应触发；简单命令输出、纯事实问答、闲聊、翻译润色默认不触发，除非内容本身是研发规则、方案或代码 Review。用户只是问本地是否需要部署、部署哪个服务、只重启哪个 target、deploy 参数含义时，不要把“部署”扩展成测试或生产发布。
