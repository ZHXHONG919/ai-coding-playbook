# D09 独立设计审查摘要

本记录由主线程根据 `/root/global_node_audit` 与 `/root/contract_isolation_design` 的实际工具消息整理；不是逐字原始报告。两者只读候选规则，未改文件/跑测试，均继承当前设计背景，不能当冷启动行为测试。审查期间主线程在改中央文件，因此区分初读发现和后续已修内容，不将其视作固定终版 CR。

共同发现：依赖只看整批 accepted，缺少协议与真实能力的区别；首次开工门槛复用于续跑易整体停工；交接缺少统一必要信息导致约束丢失；旧 TODO 模板仍要求人工逐项对齐；无限探针可能占用其他可交付工作时间。

采纳：用现有任务调度和交接处理局部缺口，沿任务拆分表达真实责任，不新增状态字段；中央文件统一语义，阶段保留专属细则。五节点、六项交接、有限探针、契约隔离与回收相互衔接。防止假统计、权限默认放行、核心导出未实现却 complete。未采用按节点固定新建 Agent/报告或放松整体真实验收。

最终一致性由另一次固定内容复核给证据，见 autonomy-independent.md；本记录只支撑设计取舍来源。
