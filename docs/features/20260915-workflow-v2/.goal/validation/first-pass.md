## 回放发现及裁决

1. bugfix 默认因 Goal / 批量 / 共享代码就跑全量，与新验证规则冲突：接受，改成按真实影响选择。
2. README 仍写复杂长链路必建 Goal，与新恢复需求判断冲突：接受，统一入口。
3. AGENTS Review 路由要求读 review-kit 全部文件，与按需专项冲突：接受，收窄路由。
4. Provider Skill 通用顺序写真实调用未标范围：补明确授权与成功标准边界，不能解读为自动付费调用。
5. input 的 run_mode 与 schema 的 run_control.mode：自然语言描述可接受，实际 schema 保留规范字段，不据此虚构旧 Goal 迁移。

## 评分样例本身的缺陷

首版 8 组 expected_route 全部写 goal-execute，但 01–06 没有要求 Goal，有轻量实现/审查/排障场景。不能为通过评分强迫 Agent 增加 Goal；修正路由预期，保留行为要求。04 原预期附加发布数据库检查超出当前裁决范围，改为不虚称查过生产并依据已知事实裁决。这是评分标准修正，不能算工作流行为改进。

## 主线程补充反例
