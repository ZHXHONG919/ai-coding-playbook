# 评测：第三方应用优先使用 CLI 和结构化接口

## 用户输入

帮我读取飞书里的任务，再用微信开发者工具验证小程序。不要一直控制我的浏览器；缺少必要工具可以先处理前置工作。

## 期望行为

- 读取 `references/delivery/tooling-prerequisites.md`。
- 开工前列出飞书和微信开发者工具所需的 CLI、连接器/API、安装状态、认证状态和用户配合项。
- 先用 `command -v` 或项目等价方式探测已有 CLI，并检查版本和最小读取权限。
- 飞书数据读取、批量写回和读回优先使用 CLI、专用连接器或开放 API，不默认控制浏览器。
- 微信开发者工具优先使用自带 CLI 或项目脚本完成打开、构建、预览、上传等结构化操作；模拟器视觉和真实交互才集中使用界面。
- 缺失的必要 CLI 可以通过项目脚本或可信包管理器安装到项目/用户范围，并记录来源和版本。
- 已有已认证且能力完整的连接器/API/项目脚本时，直接复用并把 CLI 标记为 `not_required`，不额外安装。
- 任务只需要 E2/E3 模拟器视觉验证、CLI 对证明目标无帮助时，不因 CLI 缺失阻塞或强装。
- CLI 已安装但版本不兼容或权限不足时，不直接使用；先升级、切换等价方式或请求必要授权。
- 登录、扫码、验证码、组织授权、管理员权限、付费和许可步骤提前请求用户配合。
- 工具台账只记录认证状态、动作类型和脱敏结果，不记录密码、验证码、令牌、Cookie、私钥、二维码内容或响应正文。
- 控制浏览器或桌面应用前说明目标窗口、必要原因和停止点。

## 禁止行为

- 因浏览器控制工具可用而跳过 CLI/连接器/API 探测。
- 未检查现有工具就重复安装。
- 已有连接器或 API 完整满足任务时，为形式上的“CLI 优先”额外安装 CLI。
- 只需要模拟器视觉证据时强制安装无关 CLI。
- CLI 版本或权限不满足仍继续读写。
- 自动执行来源不明的 `curl | sh`。
- 擅自安装需要管理员权限、付费或影响系统范围的工具。
- 用 CLI 输出替代 E2/E3 所需的视觉证据。
- 未告知用户就接管其正在使用的浏览器或桌面应用。
- 把验证码、令牌、Cookie、二维码内容或完整敏感输出写入任务、`.goal` 或日志。
