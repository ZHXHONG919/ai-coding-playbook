# 恢复核验

你是本轮独立核验者，没有参与实现。用户刚更新了界面要求，要求继续完成 Goal；代码里的用户修改已经交回写权限。按随任务提供的 Goal v3 指引，只读核对当前结果、历史证据的适用性及剩余验收，不改代码或记录，不需要再派人。

先读用户最新决定、当前结果及所引用来源，报告自己的操作、预期和证据复用范围；之后再读 `implementation-note.md` 和历史报告。应用为可执行状态模型，运行 `node app.mjs` 可观测当前结构及数量；它不能证明真实视觉还原。

最终只返回一个 JSON 对象：`{"results":{"结果编号":{"state":"passed|failed|pending","reused":false,"observed":"具体动作与观测，以及历史证据是否仍适用","evidence":["命令或记录引用"]}},"limitations":[]}`。`reused` 表示最终结论是否采用原有核验证据；新增运行观测仍如实列出。
