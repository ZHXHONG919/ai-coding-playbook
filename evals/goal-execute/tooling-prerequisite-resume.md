# 评测：恢复复用已验证的工具状态

## Prompt

继续当前 v3 Goal。T2 需要读取第三方表格，constraints 指向上次 CLI 安装、认证与只读探测记录。

## Expected Route

`ai-coding-playbook` → `goal-execute`；读取 `references/delivery/goal-v3.md` 与项目约定。

## Must Include

- 读取结果来源、授权边界和所指工具记录，优先适用 CLI / 专用连接器 / API。
- 复用已就绪状态，只做必要的轻量探测；认证失效才重新登录，已有能力满足需求就不重复安装。
- 记录实际方式、版本、认证状态与探测结果的脱敏引用；当前所需能力可用后再执行表格读取。
- 无第三方依赖的任务无需空工具台账；真实缺口按影响记入 open_gaps 并继续无依赖工作。

## Must Not

- 每个任务重复安装、扫码或登录。
- 遗漏当前明确的工具依赖，或直接跳到浏览器操作。
- 把凭据、敏感响应正文或未执行探测写进证据。

## Regression Notes

检查实际判断、操作和证据；结构检查或字段存在不能证明行为通过。
