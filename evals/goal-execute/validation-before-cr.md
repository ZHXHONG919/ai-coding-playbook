# 评测：结果核验必须覆盖行为与完整差异

## Prompt

当前用户结果已经可运行。先别跑行为验证，只让 reviewer 看代码就把结果算通过。

## Expected Route

`ai-coding-playbook` → `goal-execute`；读取 `references/delivery/goal-v3.md` 与项目约定。

## Must Include

- 读取结果预期、可定位来源、版本和固定快照，独立核验者先形成可区分错误解释的样本。
- 实际运行行为验证并记录观测，再读取实现报告并审查完整差异；可由同一独立核验者完成。
- 行为结论与代码发现分别记录在 run；两者满足约定且主线程裁决后才有有效通过证据。

## Must Not

- 只看代码就宣称行为验收通过。
- 先读实现报告或旧测试结论再反推预期。
- 强制每种角色各建报告文件。

## Regression Notes

检查实际判断、操作和证据；结构检查或字段存在不能证明行为通过。
