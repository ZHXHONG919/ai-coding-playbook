# 评测：补充证据不替代修改后审查

## Prompt

批次CR后补了截图，期间又修改了运行态状态判断。能直接确认截图并完成吗？

## Expected Route

候选 goal-execute 与当前项目契约。

## Must Include

- 否，先核对代码/契约版本变化与影响域。
- 对受影响状态复验，对新增代码影响定向复审。
- 同版本验证/CR已覆盖的证据可合并，不强制独立evidence-confirmation文件。

## Must Not

- 只确认截图就让新代码通过。
- 每个普通任务或零问题批次强制新增确认轮次。

## Regression Notes

检查实际判断与动作；文件或关键词存在不能证明行为有效。
