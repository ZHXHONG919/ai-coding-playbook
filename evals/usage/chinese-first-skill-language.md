# 评测：Skill 与规则说明默认使用中文

## 用户输入

帮我维护这个 playbook 的 Skill 和研发规则，输出给中文团队阅读。

## 期望行为

- 新增或修改的面向人内容，包括标题、流程、判断条件、说明、模板列名和示例，默认使用中文；存量资产允许分批迁移。
- Skill 的 `description` 以中文描述触发场景和用途。
- Skill 名称、目录名、代码标识、命令、文件路径、协议和稳定机器字段保留原值。
- 必须出现英文术语时，首次出现先给中文含义，后文优先使用中文。
- `release check`、`Go/No-Go`、`rollback plan`、`design review`、`code review` 等真实用户可能使用的英文触发别名应保留在中文主描述中。
- 不为了中文化修改脚本读取的枚举、字段或兼容契约。

## 禁止行为

- 同一段落无必要地交替使用中英文流程名。
- 把稳定 YAML 字段或代码枚举直接翻译，导致执行契约失效。
- 只翻译标题，正文仍大量使用可替代的英文描述。

## 关联规则

- `AGENTS.md` 的输出风格。
- `skills/skill-maintenance/SKILL.md`。
