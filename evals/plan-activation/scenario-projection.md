# 用例定义在模型、图和协议中一致，实例验证同一含义

## Prompt

在已关联规则的项目中分别使用普通“做方案，先不实现”“整体重构已有方案，先不实现”和成熟字段的简短方案请求。输入包含已确认参与者、相关现有能力和真实结构；不告诉作者模板路径、待修偏差或评分。

## Expected Route

入口描述在启动读取前即可见：先实际取得或复用入口及项目约定正文，据约定选根，再准备full或light方法与模板；正文可分次或有序合批，项目仍先于方法，整组方法完整返回后，发现相关模块并按依赖读取定义。入口路径与名称发现可提前，已有本轮同版完整正文可复用，不能用后来重读抹去先前实际提前采用方法。原生注入猜测、哈希、文件名或不同时刻零散行拼接不能代替正文；准备与依赖细读不并发，截断补齐。完整请求按方案阶段、编写规范和正式模板形成设计；轻量请求共用准备后仍走轻量阶段，不为共用方法强制八章、全字段表或状态图。已有设计重构须回到确认输入，生成一份连贯的当前方案。

## Must Include

从业务来源及公共身份约定构造参与者，不能先补旧入口资格再把这个过强的起点贯穿全文。复用现有能力前比较实际条件；存在额外资格差异时，以业务已允许却缺少该额外条件的合法设计样本走读，已核实等价关系除外。整体相容可完整采用，只有结果或查询部分相同则限于实际共用范围；受限接入明确服务端范围及调用能力，保留本次未要求改变的旧授权与消费者。API采用用例与工程映射结论，以相同身份事实完成读取、选择和动作。真实未知只限制相应集成，不让已确认结果整体延期。

关系先确定端点代表整个共享类型还是明确条件子集，再按业务角色及相关变化推导两端数量。用本次参与、未参与关联的合法旧对象和变化后保留的对象共同检验；领域子集映射共享物理表时，不能要求其他用途的旧记录都有本次关联。领域图、ER、状态图和协议采用相同模型，不增关系台账或固定图数。

消费者需要的事实在原定义位置形成可直接取值的字段及层级；嵌套对象/数组有确定结构，完整旧类型或明确字段子集可引用，不把新类型名和事实种类当完整定义。查询先按参与者要显示、选择、筛选与回看的结果定义，再组织路由及共用结构；设计中增加的读取也回到同一位置，同一响应不同动态集合各有范围、筛选、顺序及读取边界，无业务顺序要求可明确无序或消费者排列，固定值列表沿用完整值域，不强迫所有数组分页。属性范围从本次直接读/比较、写入及消费的事实确定，不只看新增列或值集扩展；合法输入与动作累计、转换后的结果分别推导，再选兼容的存储和传输表示。已知结果超出现有表示时给候选改法及消费者调整，不把该需要整体延后，也不由单个边界样本发明业务上限。旧机器值可引用，缺少中文就在负责位置补齐，初值/null同样承接，其他无关字段不展开。

先在原负责位置交付动作结果边界、查询业务含义、实际依赖属性及关系的完整定义，再落实存储/API并生成图。采用候选模型、表示或协作方式后，沿变化事实反查受影响的既有契约，存储和协议给候选接续方式、过渡期可见行为及启用/退出条件；实际消费者接入未知不延期已知契约冲突的设计。动作相关情形有服务器结果；查询事实及比较能表达已确认顺序；每条关系的两端数量可读回同一双向定义；旧属性只有机器值时中文在负责位置补全。范围按业务/类型而非样本确定，不做全系统组合或无关字段审计。随后按消费者完成目标的真实顺序安排必要读取/续取、选择、执行和结果后读，从满足相关模型与生命周期约束的少量起点生成实例；具体请求/响应只在统一场景区按起点成对生成，接口保留完整契约并引用单元；额外验收分支同样生成。简单结果直接推得，非直观规则或多步集合变化用已有工具局部核实；人工注错说明用途，推演与工具验证分清，不启服务或另交文件。调用者、对象及变化后的资格可恢复，独立分支自成段，通用协议不混入操作时序。各实例分别成立，正确路径不能抵消缺定义或其他矛盾；并发按实际交错，未知仅限真实依赖。轻量仍用短说明或精确引用，不增加台账、图数或八章义务。

## Must Not

不从旧接口权限推断业务角色必然持有该权限，不把必要读取的调用限制扩大为全部动作资格，不靠删除旧守卫、补发权限或假定内部接口已存在让调用成立。不因两条关系连接相同对象而复制两端数量，也不把历史归属当作当次关系仍存在的证明。图语法或布局通过不能替代关系含义正确。

## Regression Notes

保留对照首稿和原判据，以新上下文重跑三类，普通请求与业务输入不变。准备证据按完整正文、选定根及实际依赖顺序核验，必需项目定义范围在生成前独立确定；同时保留全部输入覆盖信息，无依赖实现不强制细读。读取器另测真实输出、缺失/截断、顺序及只读性，不能仅按自报摘要判通过。输入覆盖相关既有用途的共享类型、新的嵌套消费或有限取值，以及需要差异数据才能判错的局部改动；也继续覆盖旧入口条件和关系解除。独立评估者先从业务形成预期，再读未修订首稿，不读候选规范或旧评分。静态检查只证明结构，不能按新增关键词或修后稿宣称行为通过。
