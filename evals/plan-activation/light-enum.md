# 轻量字段契约的首稿回归

## Prompt

给设备补一个来源类型字段，沿用现有管理页和权限，做个简短方案，先不实现。

## Expected Route

统一准备后采用轻量方法和模板，不为字段改动展开完整八章或Goal。

## Must Include

按目标项目已确认的来源类型定义，在首稿说明机器取值及逐值中文含义、可空和省略在创建/更新/读取中的含义、应用初值与数据库默认方案，以及存储和接口对应。允许具体引用可取得的完整定义；数据库不设显式默认值也是有效选择。保持旧数据、权限、租户和分页行为。

## Must Not

不把null补成新的枚举，不新增无需求的取值、关系表、状态或基础设施。不为原有未变字段重新盘点全部枚举，不把轻量方案升级为完整方案。

## Regression Notes

作者只收到普通请求及项目输入，不接收此判据、模板路径或历史反馈。通过正式安装脚本关联隔离规则副本，项目AGENTS不预置规则根；记录实际安装入口、所选根、正文读取、来源与输入哈希，独立判定未经补写首稿。保留位置名称文本场景作不涉及枚举的轻量对照，确认通用契约要求不会造成过度展开。
