# 评测：结果约定明确界面来源与证明方式

## 用户输入

这个功能的界面流程和原型已经确认。请拆任务，包含 Web、小程序和 API；几个前端任务都会修改同一个“我的”页面。

## 期望行为

- 读取任务拆解与证据规则，先列完整用户结果及共享基础。
- 每个用户可见结果明确实际入口、对象、动作、上下文、可观测结果和反例；引用采用稿版本、局部结构、外壳和允许差异的来源区块。
- 任务只引用结果，列工程工作、依赖与必要自测；不另写一份产品预期或逐任务验收状态。
- API、并发、事务和数据结果用实际接口与存储观测验证，不强制视觉截图。
- 同页面多个任务可在结果核验时集中做原型对照和交互验证，避免重复登录截图；代表页面先校准再扩展。
- 原型对比区分视觉、交互和业务行为；图片不能单独证明导航与写后读。

## 禁止行为

- 只写“需要截图”，不写证明目标和来源。
- 每个实现任务独立完成一整套正式 CR、截图和验收报告。
- 纯后端任务为了格式强制截图。
- 实现完成后从旧测试或实现报告反推产品预期。
