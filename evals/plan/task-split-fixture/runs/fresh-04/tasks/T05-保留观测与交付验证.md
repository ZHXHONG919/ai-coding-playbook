# T05 保留、观测与交付验证

类型：共同生命周期与质量能力；负责人main；关联R1/R2、F1/F2。依据需求R-08、非功能目标，方案v12第5/7/8章。无新增界面，界面基线沿T03/T04，不新建运营统计页。

## 1. 目标与行为

保留未完成批次，完成后至少90天保留结果及去重；审计仍按既有策略，不随批次清除或清空历史batch_id。每日小批事务锁候选，必须completed_at已写入、早于当前90天且所有项终态；缺完成快照先补写，不删除。先按batchId删项再删批次，去重随批次解除，允许旧key之后当新请求；不依赖FK或级联。锁冲突跳过，重入/故障只能延长保留不能扩大范围。

观测最近5分钟持久终态中的系统错误比例（同快照替换窗口，不累加扫描），示例样本≥100且比例>1%提醒后端值班；低流量可查失败项。最老未完成年龄来自批次created_at，不把60秒恢复目标当总年龄告警；阈值/持续窗口沿用实际监控策略，待接入核实。采集失败不报0积压/0错误。日志关联batchId/contentId/worker/attempts，不记lease_token，不用无限ID指标标签。异常由后端值班及数据负责人核查，复用既有数据库健康/日志，不建监控平台与全量巡检。

## 3. 验证

| 检查项 | 样本及入口 | 观察与预期 |
| --- | --- | --- |
| V01 / S01 | 真实POST/worker生产完成/未完成批次；用受控时钟推进90天前后，或准备明确标识的合法历史初态夹具，仅用于清理读取/删除边界验证，不拿它证明审核生产。带未补写完成时间、锁冲突和审计旧记录 | 正常清理入口前后同库存储读回：未完成/未到期不删，快照缺失先补不抢删，到期仅删项/批次，审计与历史ID留存；重入无扩大删除，清理后同key真实POST可新建。执行前检查连接和SQL谓词，不清库、不建隔离库 |
| V02 / S02 | V03真实负载/故障与健康项产生结果，受控时间窗口及采集失败；明确初态夹具只用于统计口径边界 | 监控查询同快照核对窗口分子分母，重扫不累加、低量不错误触发，最老年龄正确；采集失败不是0，日志无凭证及无限标签；告警路由/值班归属读回，实际阈值未确认则保留缺口 |
| V03 / S02 | 健康依赖下10并发×每批100条，由真实POST及worker生产；确定机器/库规模、重复次数与样本量；另真实领取后中断且有另一健康实例 | 统计提交/查询各P95≤300ms、95%批次30秒完成；60秒仅恢复领取，另观察完成及无重复审计。数据从真实请求计时与持久事实取得，失败回查锁等待/耗时，不能用Mock或单次成功替代指标 |

## 4. 缺口与发布边界

实际环境、样本量、监控覆盖、阈值及正常命令由main在S02验证前落实；只阻止对应质量结论，不重开已定业务问答。当前未测量任何性能或恢复目标。发布前按release-safety-review及项目SOP：先迁移再启用接口/worker，回退先停止领取并等待在途事务、保留新表及记录，由兼容版本续接未完成任务。本请求没有发布授权，不执行迁移、业务服务、数据库清理或发布。教学包完成不等于业务Goal完成。
