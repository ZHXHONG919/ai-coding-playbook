# T07 运行观测、容量与交付验证

共同运行能力；owner：main；关联R1、R2、F1、F2。采用F1；来源：[方案第7/8章](../../../../../../docs/examples/plan-output/plan.md)、[需求非功能目标、A-01～06](../../../../../../docs/examples/plan-output/requirements.md)。无界面变化；不是新增汇总功能。

## 1. 目标、行为与协作

沿用现有日志/数据库健康观测，不建通用监控平台或运营统计。日志关联batchId、contentId、worker ID、attempts，不记凭证、不以这些ID做无界增长指标标签。后端值班查系统故障/滞留，数据负责人查原子结果异常。

系统错误比例用同一快照最近5分钟持久终态及processed_at计算，刷新窗口不重复累加；至少100样本且>1%是待校准示例阈值。低流量允许直接查失败项。最老未完成年龄从关联批次created_at取最大，查询失败不能记0；本例不另设年龄告警，接入时核实既有覆盖及阈值/持续窗口；60秒恢复不是积压年龄阈值。不默认增加每分钟全量审核联表巡检。

## 2. 实施步骤与依赖

S01：T03/S01具备真实调度入口后接入必要日志/指标，V01通过只证明观测口径；监控覆盖不足由main在原任务记录责任与回收点，不假称已上线告警。

S02：T03/S02真实路径和T06/S01后，核实环境/规模/样本量，执行V02容量与恢复验证，汇集A-01～06及保留验证，固定完整基线差异做独立验收/CR。发布仅写交接，不实际发布；先迁移再启接口/worker，回退先停止领取等在途结束再回应用，保留新表/批次/审核记录，由兼容版本接续未完成任务。不得删除任务掩盖积压。

## 3. 完成条件与验证

V01：正常执行、重复采集窗口、低流量、采集失败样本，经实际采集入口核对数据库事实和日志，比例不重复计数、失败不伪造0、凭证不出日志。既有覆盖待实查，阈值仅初值。

V02：明确机器、数据库规模、样本量及依赖健康条件后，10并发批次×100条，分别统计提交与查询P95≤300ms、单批95%≤30秒；数据库健康且另有工作实例时中断后60秒恢复领取，另观察最终完成及无重复审核。失败定位锁等待/领取/执行，不改业务承诺或引入队列。30秒租约、1秒扫描、并发4、2/5秒退避均待实测；没有运行数据不能宣布达标。复用T04/T05/T03既有有效证据，不为运维再重复全量验收。

## 4. 接入缺口

虚构项目无实际机器、运行命令、样本量、监控覆盖。main在接入前补中性事实再执行，不凭空编造pnpm命令或环境成绩。发布与生产/付费操作仍需对应授权；教学包不是授权替代。
