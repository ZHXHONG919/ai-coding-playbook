# T03 选择确认与提交

类型：用例功能；负责人main；关联结果U1。采用[夹具F1](../../../adoption.md#冻结范围)，需求v1/方案v12；业务定义见[需求](../../../../../../docs/examples/plan-output/requirements.md)及[方案](../../../../../../docs/examples/plan-output/plan.md)。只写教学交接，不执行下述工程动作。

## 1. 目标、范围与职责

P1选择、同页确认、提交意图及202后导航。数据沿已有content.review审核列表读取，不依赖content.read，不改变单条通过。调用T01协议和T02能力，不在页面复制审核规则。

## 2. 具体行为与协作

按R-01/R-04、UC-01/API-01和P1：无选择“批量通过”禁用。勾选后打开同页“确认批量通过”，展示实际数量；“取消”仅关闭并保留选择、不发请求；只有“确认提交”调用API-01。1～100条不能重复，已通过项不提前排除，内容不存在由执行逐条处理。

每次确认意图生成请求标识；网络响应丢失/5xx保持原标识原参数重试；409不自动换标识。主动返回列表重新选择提交是新意图。202按batchId导航/review/batches/{batchId}，显示处理中而非审核成功。401重新登录，403提示无权限且不自动重试，400修正输入；错误保留可恢复上下文。防止重复点击导致生成新标识。
