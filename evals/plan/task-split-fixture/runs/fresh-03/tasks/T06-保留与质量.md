# T06 保留清理观测与质量验收

类型：共同能力与质量集成；负责人main；关联结果F1/F2/U1/U2。采用[夹具F1](../../../adoption.md#冻结范围)，需求v1/方案v12；业务定义见[需求](../../../../../../docs/examples/plan-output/requirements.md)及[方案](../../../../../../docs/examples/plan-output/plan.md)。只写教学交接，不执行下述工程动作。

## 1. 目标、范围与职责

负责R-08与方案第5/7/8章清理、监控、容量及最终验收，复用T02/T05事实；不另建运营统计平台。main落实环境、数据和资源，后期配置接近执行再细化，不删除范围。

## 2. 具体行为与协作

每日小批次事务锁候选：completed_at早于当前90天且全部条目终态才删；缺完成快照先补、未完成永不清。先删条目再批次/去重，不依赖FK/级联，不删审核记录或清历史batch_id。可重入、锁冲突跳过、故障只延长保留；清理后旧key可为新请求，前端不把超保留期当网络重试。

5分钟同快照SYSTEM_FAILED/终态比例，刷新窗口不重复累加；示例样本≥100且>1%提示，实际阈值按既有策略落实。最老未完成年龄按关联batch.created_at，不把60秒恢复作为批次总年龄阈值；采集失败不伪装0积压。日志含batchId/contentId/workerId/attempts，不含token，不把ID作高基数标签；值班查故障和滞留，数据负责人查事务。

需求负载10并发批次×100条，提交/查询P95≤300ms，健康依赖下单批95%≤30秒；DB健康且另一worker可用时60秒恢复领取。机器规格、数据规模、样本量未明确，须量测前落实；30秒租约、每秒扫描、并发4为待验初值。

发布交接只准备：先迁移再启接口/worker；回退先停领取、等在途事务再回退应用，保留新增表、批次及审核历史，由兼容版接续。当前不执行发布。
