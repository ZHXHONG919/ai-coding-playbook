# T04 结果查看与完整体验集成

类型：用例功能；负责人main；关联结果U1/U2。采用[夹具F1](../../../adoption.md#冻结范围)，需求v1/方案v12；业务定义见[需求](../../../../../../docs/examples/plan-output/requirements.md)及[方案](../../../../../../docs/examples/plan-output/plan.md)。只写教学交接，不执行下述工程动作。

## 1. 目标、范围与职责

负责P2路由、结果/轮询/失败恢复和返回，承担P1→P2→列表整个功能组体验门禁及唯一首次真实接线。事实由T02投影，不用内容当前状态覆盖历史结果，不伪造终态。

## 2. 具体行为与协作

按UC-02/API-02、P2从地址batchId读取；有未完成项每2秒查，30秒提示“仍在处理，可稍后查看”，全部终态停止。完成不等于全部成功，展示成功、业务失败、系统错误及原因；PROCESSING_ERROR提示“处理失败，可重新提交”。网络错误保留已显示结果，“重试查询”恢复读取，返回内容列表不隐含新提交。刷新/保存地址/浏览器历史还原同batchId，无跨设备历史列表承诺。401重新登录、403无权限、404不存在或他人批次统一不可访问，按code/message/traceId反馈不暴露内部异常。

## 6. 缺口与变更处理

图缺失、浏览器不可用或未操作状态保留缺口并阻止本组真实后端，不能交给用户补证明。全部进度仅Goal status，正式验收在固定版本独立观测/CR，不以工程done替代结果通过。
