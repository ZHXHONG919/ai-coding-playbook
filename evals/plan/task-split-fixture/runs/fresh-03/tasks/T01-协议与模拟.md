# T01 协议与开发态模拟

类型：协议准备；负责人main；关联结果F1/F2/U1/U2。采用[夹具F1](../../../adoption.md#冻结范围)，需求v1/方案v12；业务定义见[需求](../../../../../../docs/examples/plan-output/requirements.md)及[方案](../../../../../../docs/examples/plan-output/plan.md)。只写教学交接，不执行下述工程动作。

## 1. 目标、范围与职责

固定已定场景与协议，提供服务端开发态模拟供T03/T04经正常请求层消费。main收口HTTP、内部事务接线和替换点；不提前实现真实数据库或worker，不证明权限/去重已成立。

## 2. 具体行为与协作

方案第4/6章：POST /api/review-batches，Idempotency-Key为必填UUID，action必填APPROVE，contentIds为1～100个不重复UUID；202包含batchId/resultUrl。GET /api/review-batches/{batchId}全量至多100项、contentId升序。resultUrl是API地址，浏览器地址为/review/batches/{batchId}，不能混用。

完整字段、必返、null、时间、枚举与错误严格引用API-01/02表；内部RUNNING/等待重试统一对外PENDING。覆盖处理中、混合终态、系统错误、400/401/403/404/409、网络及5xx。按机器码反馈，不能省略字段或以null代替未定义枚举。

内部协作按第4/5章：可信HTTP入口提供租户/操作者；批次应用服务创建/找回与查询归属；执行模块领取与恢复；内容approveWithAudit与条目存储共享事务。HTTP签名不代替领域方法约定，实现时复用既有签名，不在各入口另造判断。

模拟在服务端业务实现后可替换，不在组件或浏览器拦截造结果。只在开发态显式开启、内存夹具无真实副作用，生产禁止；真实失败不得回退模拟成功。main负责T04/S03接回、S04清理，保持路由/响应/错误语义。
