## 执行依赖与近期安排

编号不是顺序。P1选择→同页确认→P2结果→重试/返回属于一个连续体验组。先契约，服务端模拟，完整前端体验，再常规真实后端。不能将模拟准备与真实保存合并一步。

| 步骤 | 前置 | 输出与继续条件 |
| --- | --- | --- |
| T01/S01 | 采用协议 | 协议核对及替换点；不等页面完成 |
| T04/S01 | T01/S01 | 单体审核服务内显式开发态API-01/02模拟，正常HTTP可调；无真实副作用 |
| T04/S02、T05/S01 | T04/S01 | 完整体验；采用稿位置→预期动作/文案/请求时机→实际变化及请求或无请求→证据→差异/未验，记在这两份任务的执行记录中；完整覆盖才放行 |
| T01/S02 | 上述两步体验有效 | 批次表、迁移、去重/查询真实能力；连接目标与SQL先核对 |
| T02/S01→T03/S01 | T01/S02，前端体验有效 | 最小真实生产/消费adapter及事务/租约接线；属于F1内部实现，不依赖被基础核验阻止的完整消费者 |
| T01/S03 | T01/S02、T02/S01、T03/S01 | F1真实验证与专项CR；仅任务done不放行真实消费者 |
| T03/S02 | F1当前有效证据 | 常规执行进程、轮询与结束补写 |
| T04/S03、T05/S02 | T03/S02、F1有效 | 保持路由逐项替换；最早真实路径为一待审、一已通过，核对内容、审核记录和条目 |
| T02/S02、T03/S03、T06/S02/S03 | 真实路径及各文档具体条件 | 成对入口、恢复、保留、观测与容量补验；接近执行细化目标项目命令 |
| T05/S03 | 相关真实能力就绪 | 合批独立R1/R2验收和CR，不能等最终报告来替代早期F1检查 |
