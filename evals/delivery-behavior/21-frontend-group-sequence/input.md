# 场景输入

一个后台需求包含两个可独立交付的功能组：A 为资料列表与编辑弹窗，B 为操作记录筛选与详情。原型、领域职责和技术设计已确认，用户已授权连续实现。A 约定了查询、编辑、字段校验、保存、删除，以及加载、空态、无权限、提交中、失败重试；B 约定了筛选、分页、详情及对应异常状态。身份规则沿用现有实现，没有待验证的高影响技术未知。两组的新接口只有路由草案，字段、错误响应和分页规则尚未整理。

请说明开工顺序及 A 组可以开始正式实现服务端的时点。再判断这个后续截点如何推进：A 已按约定接口完成全部前端交互和状态的自测，B 只完成列表展示；此时有两名执行者，资源分工无冲突。用户没有要求逐任务审查或再次确认。请列出两人的下一项工作，以及哪些结果仍未验收。
