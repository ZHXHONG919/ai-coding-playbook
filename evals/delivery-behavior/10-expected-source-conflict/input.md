# 旧测试与当前有效规则冲突

项目的取消截止规则如下：

- 当前有效且已由用户确认的业务规范 R-12：“只能在截止时间之前取消；到达截止时刻即不可取消。”
- 旧实现使用 `now <= deadline`，旧测试在两者相等时断言取消成功。这只能说明当前实现行为。
- 用户最新要求：“按 R-12 修正边界，其他行为照旧。现有成功取消后的通知内容保留，已经确认过了，不用再问。”
- 本轮没有时区换算、并发或数据库变更，只涉及同一时间源下的边界比较；现有接口测试可以调用实际取消入口并读回状态。
