# 通用审查清单

审查时机、固定版本、并行验证、主线程裁决和修复复审统一遵循 `references/stages/review.md`，不在此另设预检或逐任务门禁。

根据本次改动选择检查：

- 实际行为是否符合已确认需求，是否误拒绝既有合法路径。
- 共享字段、权限、状态、身份或持久化规则改变后，调用方及恢复路径是否仍一致。
- 空值、错误、重复请求、并发和资源边界是否有具体风险。
- 测试是否经过真实生产入口、观察实际输出，期望值是否独立于实现。
- 修复是否只覆盖当前反例而遗漏同类消费者或状态转换。
- 验证结果对应哪个版本，还有哪些交付改动未检查。

只加载与变更相关的 `architecture.md`、`database.md`、`security.md` 或 `typescript-react.md`；无需每轮遍历全部专项。
