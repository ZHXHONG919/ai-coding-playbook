# Review Kit：通用审查流程

## 流程

1. 明确目标：本地 diff、PR、指定模块、方案文档。
2. 收集证据：diff、项目文档、测试结果、相关调用链。
3. 预检：lint、typecheck、test、build；失败视为风险。
4. 审查：正确性、安全、性能、并发、数据一致性、可维护性、测试。
5. 输出：问题优先，严重程度排序。

## 快速清单

- 是否满足需求和方案。
- 是否破坏现有行为或兼容性。
- 是否有空值、边界、并发、幂等问题。
- 是否有权限、注入、敏感信息风险。
- 是否存在 N+1、无界循环、资源泄漏。
- 新增行为是否有测试或 smoke。
