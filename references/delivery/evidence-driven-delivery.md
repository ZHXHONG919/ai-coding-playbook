# 证据驱动交付

> 围绕已确认行为选择最小充分证据。每个结论都说明观察到了什么、能证明什么；普通任务共享批次证据，不重复搭环境、写报告或截图。

## 从行为选择证据

正常开发以有效需求、用户认可的既有行为或已确认界面为基线；修复以问题原始来源和复现结果为依据。先按 `skills/test-scope-analysis/SKILL.md` 写检查单：

```text
改变的行为 → 关键反例 / 风险 → 真实入口与观测点 → 预期结果 → 足够的证据
```

“必要自测”由这份检查单决定，不是固定执行 lint、typecheck、build、全量 test 的组合。实现者执行任务自测；关键基础及功能批次需要独立判断，审查安排统一遵循 `references/stages/review.md`。

## 观测生产行为，保持期望独立

- **实际入口：** 选能覆盖本次行为的生产函数、服务接口或客户端入口。跨模块验收尽早接通一条最短应用路径，不用多组互不相连的单测推断整体已跑通。
- **实际结果：** 响应、状态、调用次数、因果关系和存储内容必须从运行结果读取。将预期常量写进报告、读取上游状态代替最终状态，均不能证明最终行为。
- **独立期望：** 来自有效业务规则、按该规则确定的冻结样例或用户认可的既有行为；只观察到旧代码/测试如此，不自动成为验收口径。来源冲突先说明，选一个能区分最可能两种解释的输入，不用旧测试通过决定产品口径。禁止用本次实现计算期望值，再以相同计算证明自己正确；基线变化需解释原因，不能直接更新快照吞掉差异。
- **替身边界：** 可替换数据库连接、时钟、provider 等外部依赖，但保留被测业务判断。固定 provider 只校验真实请求并返回预声明响应，不在替身内重写路由、质量判定或回退决策。
- **真实写后读：** 被测代码执行写入，再从同一个存储读取；手工预填“最终记录”只证明读取功能。使用内存存储时说明与真实数据库的差距，事务/锁/约束本身的验收需要相应数据库证据。
- **能检出错误：** 高风险验收挑一个相关错误输入、断开调用或字段篡改，确认检查会失败。无需为所有任务另建完整变异测试体系。
- **模型质量边界：** 固定模型响应能证明应用如何构造输入、消费输出与保存结果，不能证明真实模型效果。若验收要求实际生成质量，应单独安排已授权环境的代表性评测，写明配置、结果和波动，不能用 mock 通过替代。

## 证据等级

| 等级 | 适用范围 | 最小充分证据 |
| --- | --- | --- |
| E0 | 重复问题、非问题、口径误解、无需运行的文档变化 | 产品口径、位置、历史提交或重复关系 |
| E1 | 后端逻辑、接口、状态、数据、历史已修复 | 针对性测试、真实接口响应、数据读回或当前路径检查 |
| E2 | 页面功能、入口、权限、状态展示 | 浏览器或客户端操作验证；必要时保留关键截图 |
| E3 | 视觉差异、复杂交互、多角色、多端一致性、真实环境问题 | 基线/实现对比、关键角色和端的同路径证据 |

等级只选择证明手段，不决定审查轮数，也不代表越高越好：

- 用户可见界面行为至少需要运行态检查；视觉、跨角色或跨端结论要有对应对比。
- 并发、事务、权限、幂等和数据正确性不能用截图替代行为证据。
- 历史已修复问题要求当前路径证据，不强制重建修改前现场。
- 多个任务共用同一路径、角色和状态时共享证据，并指明各自证明的行为。
- 无法取得必要证据时标明未验收部分及影响；仍可推进无依赖工作，不把缺口写成通过。

## 界面验证与预算

涉及界面的任务声明界面基线、需要证明的关键状态及证据门禁；无界面变化可写 `界面基线：无`、`证据门禁：接口/数据证据`。

**采用稿只定义一次。** 有确认稿时，在现有 ui-flow 或原型说明维护下面的简短索引；若来源已有这些信息，直接引用。任务、Goal、实现/修复提示按编号引用，不新建强制交接报告。

```text
UI-01：采用稿 <路径/预览入口及可定位版本>；确认依据 <已有用户决定>。
范围与比较条件：<页面/区块、状态、参考视口、代表性数据>。
保留项：<布局、字号层级/密度、关键控件；操作/反馈/跳转；业务契约编号>。
允许差异：<已授权的文案删除、真实数据替换、响应式适配等具体范围；未授权部分保留采用稿>。
```

实现者与修复者先实际打开采用稿及相关结构/样式。优先迁移可用结构、样式和组件再接真实数据；框架转换、组件库默认值或通用 polish 建议不能覆盖确认效果。只有源码而无法查看预览时，说明视觉输入缺口，不能把读源码当成运行对照。

新页面、大改版或共享视觉基础首次可运行时，在扩展复用前，以同视口、同状态、代表性数据对照一个页面/区块，先校准主要布局、层级和关键控件。把这次结果放在现有自测记录，指出采用稿、实现版本、比较条件及有意义的差异；不新增 CR 批次，不要求每个任务截图。无法对照时保留校准缺口，推进无依赖工作，不能把同一未验证布局扩散后再统一返工。

界面批次分别给出以下结论，比较原型不能只比较像素：

| 维度 | 要证明的结果 | 对应证据 |
| --- | --- | --- |
| 视觉还原 | 确认的布局、层级、密度与关键控件保持一致，差异在授权范围内 | 同视口/状态的采用稿与实际页面对照；必要时查计算样式，不默认要求所有页面逐像素一致 |
| 交互一致 | 主路径、入口、操作条件、反馈和跳转符合确认流程 | 实际点击/键盘操作与关键状态验证，截图不能单独证明 |
| 业务正确 | 数据范围、单位、权限、状态与接口结果正确 | 实际应用路径及必要读写/权限证据，视觉相似不能代替 |

视觉未验证时写“还原待验收”，不能以源码 `Fixed`、测试绿或用户将自行验证推导整体完成。用户选择手动验收时提供采用稿、当前页面及待验关键项，收到实际结果后再更新对应结论，不重复索要已给予的授权。

- 同一页面和批次集中验证，普通任务先做轻量实际查看，不反复制作最终截图。
- 保留能证明主路径、最高风险异常/权限状态和关键成功结果的材料；其余状态优先复用自动化覆盖，无需每个状态留图。
- 最终证据与代码审查可在同一固定版本并行完成，合并写入批次验收记录；不强制另建逐片 `evidence-confirmation` 报告。
- 修复改变了哪些行为或呈现，就重查哪些状态；未受影响证据可复用。纯报告变更核对事实即可。
- 客户端控制连续同类失败时，依据错误换定位或采集方式；不要无限重试。更换手段不能降低原证明目标，接口/数据不能替代视觉结论。必要登录或工具不可用时登记具体缺口和人工介入。

## 固定版本，集中验证

```text
确认行为与检查单
→ 尽早接通最短应用路径
→ 普通任务连续实现与自测；关键基础在依赖前审
→ 功能批次可运行，固定代码版本
→ 功能验证与 CR 并行
→ 主线程裁决问题，集中修复
→ 原失败路径和影响范围复验 / 复审
→ 交付版本增量覆盖检查
```

每条证据记录代码版本和相关配置；外部环境变化也要说明。固定版本期间不改同一范围，独立范围工作可继续；必须修改时重新标定版本，仅使受影响结论失效。

全量回归不是 Goal、批量问题或最终收尾的固定动作。共享规则影响面无法可靠隔离、项目明确要求或交付风险需要时运行；可信的已通过检查可复用，不因进入另一审查环节再跑一遍。修复影响域与同类问题根因分析见 `references/stages/review.md`。

## 问题来源与批量处理

从会话、工单、截图、录屏、日志、监控、失败测试、CR 或数据收敛必要信息，可记录在现有任务台账：

```yaml
source:
  type: conversation | ticket | screenshot | recording | log | test | monitoring | review | data
  reference: "<原始消息、链接、文件、日志或编号>"
symptom:
  observed: "<实际结果>"
  expected: "<已确认期望；未知则待确认>"
  environment: local | test | production | unknown
reproduction:
  steps: []
  role: "<角色>"
  test_data: "<必要数据>"
  reproducible: yes | no | partial | unknown
scope:
  parent_case: null
  child_cases: []
  related_cases: []
evidence:
  level: E0 | E1 | E2 | E3
  available: []
  missing: []
```

批量问题先展开父子/关联记录，确认范围和状态；按页面、角色、接口或共享根因成组复现与修复。共享证据不等于共享结论，每条仍说明是缺陷、非问题、重复项还是历史已修复。跨问题出现同类失效时检查共同规则，不逐工单复制补丁。

外部平台只提供来源和可选状态回写。仅在用户已授权回写时执行，并读回确认；无回写授权时在任务记录与最终回复交付结果。

## 输出

普通任务合并记录：改变的行为、自测结果、未验证部分和所属批次。功能批次合并记录：

- 基线、代码版本、配置与实际入口。
- 关键预期、运行观测、证据位置及充分性。
- CR 发现的主线程裁决、修复和影响范围复验。
- 尚未覆盖的行为、原因、负责人与交付影响。

记录帮助恢复和核验，不追求报告数量；测试绿、审查通过和交付完成分别陈述。
