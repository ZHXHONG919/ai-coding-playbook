## 行动计划

第一项先限定探针问题、最小样本和停止条件：在已有测试环境用无敏感文件，记录取消响应、任务状态与完成回调的时序，判断取消响应含义、迟到回调及处理方式。足以确定状态/错误契约和回调防护即可停止；有限样本未见回调不能证明永不回调。无论供应方如何回应，应用都须守住取消后不得变为可下载成功的规则。未解未知只阻止依赖它的工作，不借探针展开全部正式后端。
契约明确并完成必要核验后，在 API 边界模拟；补齐校验、进度、重试、取消和下载，真实操作对照原型。全组交互与状态自测通过后，按领域职责实现后端；高风险共享状态规则在真实消费者依赖前独立验证并 CR。能力逐项就绪即替换模拟、校准首条真实路径，无须等全后端完成。
本组 owner 负责模拟退出；已有记录写清启用范围、真实替换点、清理条件及未验项，明确交接后才能转交。接回真实能力并验收后清理开发模拟，生产不得启用成功替身。
第二项直接使用现有真实查询服务实现筛选，不新建模拟阶段；通过页面检查多状态数据、筛选参数与结果、分页和权限。
完成须有固定版本下的真实交互、接口及同存储读回，取消与迟到回调竞争仍不能下载，真实转换与下载路径，以及适用的独立验收、CR和最终增量检查。当前无实际调用和端到端结果，不能宣布完成；模拟、探针或构建分别只证明对应边界，不能推导完整能力、生产可靠性或成本效果。
